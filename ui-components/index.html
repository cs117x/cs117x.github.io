UI Components Library

The workspace parts that HFE Lab tools share, documented with live examples so that new applications (lifting, constrained environments, cross-sections, storyboards) look and behave like the Workspace Visualisation. Each component will be shown in the light and full-black dark themes, at desktop and tablet widths, with its keyboard and screen-reader behaviour.

Planned components

Workspace shellTop bar with menus, 3D viewport, properties panel, docked checks and status bar, with resizable splitters.
Menus and tool stripMenu bar, menu items with shortcuts and check marks, and the vertical tool strip.
Object browserScene tree with visibility toggles, collapse state and hover highlight.
Property panelsCollapsible panels, number fields with units, selects and segmented buttons.
Checks tableResults rated within limits, marginal or outside limits, with glyphs as well as colour, and editable ranges.
DialogsModal dialogs, the environment library and the full-screen prompt.
View cubeOrientation cube with faces, edges and corners to click, and a home view.
DrawingsTitle block, dimension and angle styles for PDF, SVG and DXF output.
