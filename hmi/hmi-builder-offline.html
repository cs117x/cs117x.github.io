Presets

Ready-made screens to start from or take apart. Flight and radar screens follow common, public display conventions in HFE Lab's own design; they are not copies of any manufacturer's displays. Maps are made up, not real places.

HMI Builder

Build the screens of a human-machine interface from widgets, give them simple logic, then show them live on the displays of a workstation in Workspace Visualisation, where they can be pressed and judged at the real size, distance and angle. Everything runs in this page: nothing is sent anywhere.

Building

Add widgets from the left, drag them to move, and drag a corner to resize (they snap to an 8 px grid; hold Alt to place freely). Each screen has a size in pixels; set it to the display's shape on the Displays tab. Run lets you use the screen as an operator would.

A design made in Figma or another tool can come in as a picture: Import mock-up adds it as the screen's background, and Hotspot widgets over it make it clickable, so a static design becomes a working prototype.

Presets add ready-made screens: a glass-cockpit primary flight and navigation display, a head-up display, a radar scope, and two large command and control screens (operating picture and tasking board). They share variable names, so a flight display and a head-up display show the same flight.

Logic

Variables (number, on or off, or text) hold the HMI's state, shared by every display. Widgets show them, and expressions decide what is visible or lit:

link < 20 && !ack          mode == 'AUTO'          screen == 'map'

Presses run actions, separated by ; or new lines:

goto map                  show another screen on this display
link = 8; ack = false     set variables (set link = 8 also works)
toggle satcom             switch an on or off variable
hdg = (hdg + 10) % 360    values can be expressions

Text can show variables: MODE {mode}, {alt:0} ft.

Linking to Workspace Visualisation

On the Displays tab, choose the environment, seat and display that each screen appears on. Show in 3D opens Workspace Visualisation there. While both are open in tabs of this site, changes appear in 3D as you make them, and presses on the 3D displays change the same variables here. Air-gapped, save the file and use File, Load HMI prototype in Workspace Visualisation.

The Displays tab also measures the screen on its display: the height of each piece of text in millimetres and minutes of arc at the viewing distance, and the size of each touch target. Checks of these against standards (legibility, gloved touch targets, contrast) and timed scenarios are planned.
