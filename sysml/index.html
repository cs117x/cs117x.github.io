SysML v2 Editor

    
Write a model in the SysML v2 textual notation on the left; the diagrams on the right are drawn from it as you type. Click a box to find its text; move the cursor in the text to find its box. Everything runs in this page: nothing is sent anywhere.

    
Linking the model to Workspace Visualisation

    
Two metadata definitions in the built-in HFE library tie the model to the 3D workspace:


part tactical : Display {
    @HFE::WorkspaceLink { env = "gcs-container"; role = "pilot"; node = "ws.scr.0"; }
}
verification viewingCheck {
    @HFE::Evidence { check = "viewDist#0"; env = "gcs-container"; role = "pilot"; }
    objective { verify tacticalViewing; }
}

    
Show in 3D on a linked element opens Workspace Visualisation in that environment and seat, with the object highlighted. While Workspace Visualisation is open in another tab of this site, its check results arrive here live and become each requirement's evidence (within limits, marginal or outside limits). You can also load results saved from it with Save results. Results only count for the environment and seat they were made in.

    
Supported notation

    
Packages and imports; definitions and usages of part, item, attribute, port, interface, connection, flow, requirement, constraint, action, state, verification, use case, enum and metadata; typing, specialisation, subsetting and redefinition; multiplicity; conjugated ports; connect, bind, flow and allocate; requirement subject, require constraints, satisfy and verify; entry, then, accept and transition in states. Values are kept as text. Anything else is skipped with a warning, and the rest of the model still works.

    
Keys

    
Ctrl+Space complete · Tab indent · Shift+Tab outdent · Ctrl+S save · Ctrl+O open · F12 go to the definition of the name at the cursor
